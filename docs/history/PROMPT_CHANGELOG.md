# سجل تعديلات الذكاء الاصطناعي والبرومبت — عَزْم

آخر تحديث: 2026-10-13. هذا الملف يرصد كل تعديل على البرومبتات ومسار المساعد؛ حدّثه مع أي تعديل جديد.

## البرومبتات الحالية (المصدر الوحيد للنص)

|---|---|---|---|
| استخراج الطلب | `server/ai/request-contract.mjs` → `REQUEST_SYSTEM_PROMPT` | 875 | **نص التدريب حرفياً** — لا يُعدَّل إلا مع إعادة تدريب LoRA |
