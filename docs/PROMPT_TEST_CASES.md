# حالات اختبار البرومبت — عَزْم

## شروط الثبات (قبل أي جولة)
- شغّل الموقع بـ `start-azm.cmd` (الحرارة 0، البث مفعّل، حدود السرعة).
- **محادثة جديدة لكل سؤال** — السجل يؤثر على الرد.
- نفس مجلد البيانات، والمحاكاة موقوفة ⏸ أثناء الاختبار.
- سجّل مع كل جولة: التاريخ، اسم النموذج، وزمن أول كلمة وزمن الرد الكامل.
- **أي رد رفض على رسالة ليس فيها طلب بيانات يُحسب خطأ (رفض زائد).**
